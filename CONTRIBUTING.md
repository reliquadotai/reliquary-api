# Contributing

Use Node.js 22 or later. From a source checkout, run `npm ci` and `npm test` before proposing a focused pull request. Tests use local fixtures; real account actions and paid execution require separate authorization.

Keep credentials, customer data, operational identifiers and raw security or research evidence outside repositories. Report suspected vulnerabilities privately using [SECURITY.md](SECURITY.md).

Contributions must be yours to share under the project's [MIT license](LICENSE). Include a concise description of the behavior changed and the checks you ran.
